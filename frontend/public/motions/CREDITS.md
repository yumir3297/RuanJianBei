# Motion Credits

## Qinglan Hanfu gestures (low-arm, sleeve-safe)

- `qinglan_salute_greeting.vrma`: side-turn welcome with a shallow nod; arms stay
  at rest so the bell cuffs keep hanging. Authored on `hanfu.blend` with
  `blender/author_qinglan_ceremonial.py` (3.37 s at 30 fps).
- `qinglan_bow_farewell.vrma`: bow farewell with relaxed hands and a small
  forward shift; 3.03 s, same script.
- `qinglan_exhibit_draft.vrma`: low lateral "this way" gesture; generated with
  `blender/author_guide_utility_trials.py -- qinglan`. The wide cuff still opens
  noticeably at the wrist and is not visually approved.
- All three are manual previews: no automatic triggers, no garment mesh changes.

## Manual utility gesture trials

- `jingxing_exhibit_draft.vrma`, `jingxing_remind_draft.vrma`,
  `ningling_exhibit_draft.vrma`, `ningling_remind_draft.vrma`: generated in
  Blender with `blender/author_guide_utility_trials.py` on each target rig,
  using the local geometric arm solver and TK256 MIT Clapping neutral pose
  reference (`LICENSE-TK256.txt`). Three seconds each; no wave oscillation,
  automatic triggers, or garment mesh changes. Palm readability and sleeve
  clearance remain unapproved; local preview only.

## Qinglan / Jingxing character trials (local preview only)

- `qinglan_*` and `jingxing_*` trials initially retargeted from the local
  Ningling gestures with `blender/retarget_character_trials.py`.
- Wave and farewell trials subsequently authored on each target skeleton with
  `blender/author_character_wave_trials.py`: shoulder-relative wrist targets,
  geometric elbow solve, character-specific wave amplitude and timing.
- Clap trials recompute target palm-center paths using
  `blender/author_character_clap_trials.py` and the TK256 MIT Clapping reference
  (`LICENSE-TK256.txt`). Cupped greetings remain first-pass retargets.
- Thinking still uses the existing shared GLB; common procedural trials are
  provisional, not completed Blender-authored independent designs.
- None of these drafts are automatic actions or visually approved. Model
  modification/redistribution permission is not established; do not distribute
  the avatar models or these model-specific scene files externally.

- `qinglan_farewell_wave_candidate.vrma` / `ningling_farewell_wave_candidate.vrma`:
  manual-only farewell trials generated by `blender/author_farewell_wave.py`
  on each character's armature, using the local wave solver and TK256 MIT
  Clapping relaxed pose reference (`LICENSE-TK256.txt`). Not automatic actions;
  Qinglan's wide-cuff deformation remains unresolved.

- `qinglan_farewell.vrma`: custom small farewell nod for Qinglan, authored in
  `blender/author_qinglan_farewell.py`. Relaxed pose reference from TK256's MIT
  Clapping animation; see `LICENSE-TK256.txt`. Arms remain relaxed throughout.

- `applaud_qinglan_adjusted.vrma`: Qinglan-specific bake of the TK256 MIT
  Clapping adaptation, generated by `blender/adjust_qinglan_clap.py` against
  `blender/hanfu.blend`. Paired with the local small-sleeve model variant.
  Original motion and license retained in `LICENSE-TK256.txt`.

- `ningling_wave_draft.vrma`: manual-preview greeting authored with Blender IK
  by `blender/author_ningling_wave.py`; wrist path, palm orientation, timing,
  and finger pose authored for Ningling. Uses TK256's MIT `Clapping.vrma`
  frame 1 as the relaxed pose reference; see `LICENSE-TK256.txt`.
  Not enabled in automatic greeting rotation.

- `ningling_farewell.vrma`: Ningling-specific adaptation of TK256's MIT
  `Goodbye.vrma`, using `Clapping.vrma` frame 1 as a relaxed pose reference.
  Left arm held at rest, torso sway removed, right wrist lowered/moved forward,
  finger spread reduced. See `LICENSE-TK256.txt` and
  `blender/adjust_ningling_farewell.py`; project `blender/ningling-farewell.blend`.

- `ningling_cupped_greeting.vrma`: custom Ningling cupped-hands greeting draft,
  authored and IK-baked in Blender with `blender/author_ningling_greeting.py`.
  Uses TK256's MIT `Clapping.vrma` for reference arm/finger poses (see
  `LICENSE-TK256.txt`); timing and wrist paths redesigned for this greeting.
  Manual preview only; not part of the automatic greeting rotation.

- `applaud_monk_adjusted.vrma`: Ningling-specific Blender adaptation of
  TK256's MIT `Clapping.vrma` (license below). Lowered and moved wrists forward,
  constrained wrist crossover, baked two-bone IK while retaining source hand
  orientation and finger animation. Source and reproducible script:
  `blender/ningling-clap-adjusted.blend`, `blender/adjust_monk_clap.py`.
  Original `applaud_monk.vrma` is retained for comparison.

- `applaud_hanfu.vrma`
  - Custom animation authored in Blender for this project (hanfu model, long-sleeve clap).

## Quaternius converted preview motions

- `cc0_idle.vrma`: `Idle_Loop` (2.5 seconds).
- `cc0_talking.vrma`: `Idle_Talking_Loop` (2.933333 seconds).
- Author: Quaternius. License: CC0 1.0; see `LICENSE-Quaternius.txt`.
- Source: <https://opengameart.org/content/universal-animation-library>
- Download: <https://opengameart.org/sites/default/files/universal_animation_librarystandard.zip>
- Reproduce from `frontend`: `node scripts/convert-quaternius.mjs`.
- Converted using source `A_TPose` world-space reference rotations, sampled at
  30 fps into normalized VRM humanoid rotation tracks. Pelvis/leg tracks and
  translation are omitted for stationary upper-body previews.
- Available as manual previews; not selected automatically during narration.
  Hanfu sleeves overlap across the chest during talking, and monk sleeves
  obscure the hands. Sampled front views are not a full collision audit.
