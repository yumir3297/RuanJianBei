# 一键启动前端项目

请按照以下步骤帮我启动前端开发服务器，只需要运行登录页面即可。

## 环境检查

1. 检查是否已安装 Node.js（需要 v18+）：
   ```
   node -v
   ```
   如果未安装，请帮我安装 Node.js LTS 版本。

2. 检查是否已安装 npm：
   ```
   npm -v
   ```

## 安装依赖

在当前项目目录（`frontend/`）下执行：
```
npm install
```

等待依赖安装完成。

## 配置后端地址

检查 `.env` 文件中的 `VITE_API_BASE_URL` 配置：
- 如果后端运行在本机，保持为空即可（Vite 会自动代理 `/api` 到 `http://127.0.0.1:8000`）
- 如果后端在其他机器上，需要修改 `vite.config.js` 中 proxy 的 target 地址

## 启动开发服务器

执行以下命令启动前端：
```
npm run dev
```

启动成功后，在浏览器中访问：
- 登录页面：http://localhost:5173/admin/login
- 默认密码：`admin123`

## 注意事项

- 前端默认只展示登录页面，不需要启动完整项目
- 如果需要连接后端 API，确保后端已在 `http://127.0.0.1:8000` 运行
- 如果只需要看登录页面效果，可以不启动后端，使用独立 HTML 文件 `standalone-login.html` 双击打开即可
