# 启动前端开发界面

当前游客端与管理端是独立 Vite 应用。Node 版本按锁文件中的 Vite 要求使用 `^20.19.0` 或 `>=22.12.0`；先确认 `node -v` 和 `npm -v`。

在仓库的 `frontend/` 目录安装锁定依赖并启动所需入口：

```sh
npm ci
npm run dev:admin
```

管理登录页面默认是 <http://localhost:5174/admin/login>。游客端需在另一个终端运行 `npm run dev:tourist`，默认地址为 <http://localhost:5173/>；`npm run dev` 是游客端别名。管理端和游客端开发服务器均将 `/api` 等请求代理到本机后端，实际登录和数据操作需要后端已启动并配置管理员凭据；不要将示例密码用于生产。

只需查看旧版独立登录页面外观时，可打开 `frontend/standalone-login.html`；它是单独预览，不代表当前管理端登录、认证或 API 已验证。双端启动、后端配置和跨系统限制见 [开发指南](../docs/DEVELOPMENT.md) 与 [双端边界](../docs/development/FRONTEND_BOUNDARIES.md)。
