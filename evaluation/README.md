# 旧版 100 题评测资料

本目录保存早期题集、脚本和历史报告，供追溯与比较；当前评测方法、可复现抽样及人工核验入口见 [eval 说明](../eval/README.md) 和 [人工核验](../eval/HUMAN_REVIEW.md)。两套评测的题目、判分和运行环境可能不同，不能直接合并结果。

`eval_questions.json` 是旧题集，`evaluate.py` 向本机 `http://127.0.0.1:8000/api/chat/stream` 发请求并按脚本规则评分，可能重试和写入本目录报告。执行前须阅读脚本、确认使用隔离环境、数据授权、供应商配置与可能产生的费用；不要对真实业务数据或外部服务盲目运行。既有 `eval_report_*.json` 和 checkpoint 是历史产物，并非本次验收。

此前本页引用过 30 题检索、34 题 FAQ 和 13 题盲区等小样本数字，来源为当前仓库中无法核对的旧设计文档；本次未取得其完整题集、版本、原始日志及评估环境，不能作为当前模型准确率、竞赛评分或性能提升的证据。历史完整文字仍可从 Git 历史查阅。也不能据此声称“不会编造”“所有回答均有来源”或将未经官方原文核实的目标写为赛题硬指标。

准备技术文书时，应固定代码、模型、知识版本与题集，报告样本量、成功和失败、评估方法及人工复核结果；未测项目标注未测。真实资料、供应商、设备和评测边界见 [统一验收总表](../docs/testing/TESTING_AND_ACCEPTANCE.md)。
