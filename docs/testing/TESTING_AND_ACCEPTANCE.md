## 输入与播放的专项证据

2026-10-29 的评委体验预览曾检查游客首页、地图、未登录管理端跳转和问答失败提示，并修复当时桌面中等宽度地图栏过窄。该次为静态前端预览，未连接真实后端、设备权限和正式地图/天气服务；不构成当前界面或真机验收。

行程提案的浏览器验收应覆盖：后台生成时刷新并恢复同一任务、查看差异后确认且重复提交不产生重复版本；停止等待不等于取消服务端任务；外部调用结果未知时须明确提示潜在重复费用并由游客确认重试；行程或进度改变后旧提案不得直接保存，切换游览后迟到结果不得污染当前页面。测试应使用隔离数据库、独立 worker 和明确标注的替身，另行验证真实服务。上述是验收场景，不代表全链路已通过。

游客游览还需检查同一浏览器的保存与恢复、Cookie 禁用、服务重启、跨游客访问、两个标签页的版本冲突，以及保存或确认过程中继续编辑时草稿不被静默覆盖。历史 V01 桌面及无头浏览器曾用隔离 API 和模拟供应商检查草稿、进度与提案；该阶段结果不等于当前真实供应商、手机声学输出或弱网通过。设计约束见[游客任务](../superpowers/specs/2026-10-29-tour-session-workspace-design.md)、[行程](../superpowers/specs/2026-10-29-v01-editable-itinerary-design.md)及[任务执行](../superpowers/specs/2026-10-29-w02-durable-execution-design.md)。

照片识景还应检查多候选及别名歧义、目录为空或失败、游客取消、换图后的迟到响应、目录下架或版本变化、跨站点条目及与已有景点选择冲突。来源须属于本轮真实检索；授权照片、真实模型和人工事实核查需另验收。详见[前端确认方向](../frontend/DESIGN_AND_BOUNDARIES.md)。

多轮引用需专门检查：连续两轮分别使用不同资料但相同引用编号，回看、点击和打开来源面板时，每条回答仍指向自身资料；下一轮失败或停止也不能替换旧来源。历史 fake SSE 审计曾复现全局来源覆盖旧回答；当前源码提供消息级来源入口，完整浏览器行为仍须验证。照片识别记录的可追溯性与是否保存原图应按隐私策略另行确定，短期幂等键不等于持久识别记录。

2026-10-29 的历史实施记录覆盖以下专项；结果对应当时代码和隔离环境，不代表当前真机或真实供应商通过：

- **ASR/视觉幂等**：同一操作键与请求指纹重复时复用结果，指纹不同返回冲突；新录音或新图片使用新键。该保护有进程范围和外部供应商边界，不能宣称跨进程恰好一次；当前入口见[代码地图](../REPO_MAP.md)。
- **历史回答重播**：按会话查找已保存回答，重播不重新生成问答；音色配置、旧记录回退、缓存和迟到响应有针对性测试。历史运行记录为后端 242 通过、3 跳过，前端 61 通过、1 跳过及构建通过，真实供应商和真机未测。
- **语音配置及缓存**：历史专项记录包含 profile/cache 8 项、持久化及管线 17 项通过；随后后端 256 通过、3 跳过，前端 61 通过、1 跳过及构建通过。没有对既有业务数据库执行迁移或调用真实供应商。
- **共享播放与地图生命周期**：历史专项检查播放会话接管、旧会话停止隔离、地图隐藏时取消请求与停止定位；真实设备、系统音频焦点和后台恢复仍需验收。
- **CASS 早期专项**：2026-11-07 实施记录报告前端自动化与构建、后端规则/API 20 项、相关 CASS/V01/W02 回归 60 项通过；后续本机模拟浏览器证据和现场限制见 [CASS 验收记录](../implementation/CASS_ACCEPTANCE.md) 与[比赛验收](../integration/ACCEPTANCE.md)。
- **游客语速**：自动测试覆盖本机偏好回退、普通音频、PCM、浏览器朗读及内容时间轴；真实设备音质、字幕和数字人同步仍需验收。具体范围见[多端矩阵](../COMPATIBILITY.md)。

早期测试数量不是当前版本的测试成绩；完整过程可从 Git 历史追溯。

## 验收分层

1. 静态核对：文件、路由、schema、配置和代码地图存在且链接有效。
2. 单元/服务测试：隔离 SQLite、fake provider 或内存替身验证协议和状态边界。
3. 本地浏览器联调：真实本机 API、worker、两个 Vite origin 和 Chrome 串联。
4. 真实环境验收：真实资料、模型、数据库、供应商、设备、网络和目标服务器。

前一层通过不能替代后一层。任何 Must 项为“未测”时，生产结论保持暂缓。
