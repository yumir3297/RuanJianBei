# 仓库地图可用性测试

日期：2026-10-28（Asia/Shanghai）；业务源码基线 `540568e`，测试对象为 `codex/repository-map` 分支在本次提交前的工作区版本。

## 结论

地图可用于 AI 任务定位。独立使用者初测六个任务，五个成功，一个不完整；补齐知识更新/缓存链路后，对该任务复测成功。
此结论限定为导航和工具可用性，不是业务功能、模型调用或真机兼容性通过。

## 1. 独立使用者测试

测试者不继承编写地图时的对话，先从根 AGENTS.md 进入，再按功能地图读相关源码；只有地图不足时才继续沿 imports 查找。
成功标准：能找到相关前端、API、业务/数据边界和验证入口，并正确区分静态证据与运行结果。

| 开发任务 | 初测 | 发现与复测 |
|---|---|---|
| iPhone 识图报错 | 成功 | 定位拍照/文件入口、raw-body 上传、MIME/大小校验、Qwen 服务和测试；能识别 HEIC 不在白名单内，未误称真机已通过 |
| 点击停止后音频继续 | 成功 | 定位 stopOutput、请求 token、AbortController、SSE 消费、音频 stop/resetPCMStream；能区分后端契约与前端播放验证 |
| 真实 GPS 不触发讲解 | 成功 | 定位坐标读取、触发状态机、MapView.playNarration、讲解接口和降级；找到已记录的 latitude/longitude 与 lat/lng 风险 |
| 管理员修改知识但答案仍旧 | 部分成功 | 初版缺少分块/缓存直接入口；已补上症状排查表。复测仅按新增链接找到全部边界，成功 |
| 不同系统与外层项目运行地图 | 成功，有范围限制 | 仓库根目录和外层目录命令在 macOS 实际可运行；Windows/Linux 命令可读，未在这两种 OS 实测 |
| 能否声称手机/平板/桌面全部测过 | 成功 | 使用者正确拒绝此结论，文档明确将真机/权限/弱网列为待测 |

补充修正：README 简介与目录树的两处 Live2D 旧表述统一为当前 Three.js/VRM；没有修改业务代码。

## 2. 自动化与迁移测试

主机：macOS；指定解释器 Python 3.13.16、3.14.7。地图校验和 11 项工具回归在两版解释器下均通过。
其中 `-S` 禁用 site-packages 的运行证明地图工具无需业务依赖；没有由此推断业务环境可用。

```text
Ran 11 tests
OK
Repository map OK: 8 documents, 42 registered HTTP routes.
```

另将真实地图、路由源码和所有被链接文件复制到含中文/空格的新临时目录，从该副本的 backend/ 目录运行：

| 迁移/故障注入用例 | 预期 | 结果 |
|---|---|---|
| 新路径、不同 cwd、标准库环境 | exit 0 | 通过 |
| 副本实时 JSON 导出 | 42 路由、无错误、文件路径相对化 | 通过 |
| 将副本 ChatView 链接改为不存在文件 | exit 1 并指出坏链接 | 通过 |
| 把副本后端 /stream 改名 | exit 1 并指出旧 API 引用 | 通过 |
| 恢复副本文件与路由 | exit 0 | 通过 |

故障注入只改临时副本，原业务源码没有变更。临时副本已清理。
首轮迁移时遇到继承的 PYTHONHOME 指向另一版本，子解释器启动失败；随后用 `-E -S` 忽略环境干扰，以上用例全部通过。该排查方法已加入开发指南。

## 3. 复跑命令

cwd：仓库根目录，`python` 应指向选定的 Python 3，macOS/Linux 可用 `python3`。

```sh
python scripts/check_repo_map.py
python scripts/check_repo_map.py --json
python -m unittest discover -s scripts/tests -p "test_*.py"
git diff --check
```

11 项工具测试包含中文/空格路径、错误大小写、越界及机器绝对路径、坏链接、失效 API、语法错误、动态/命令式路由与 JSON 导出。

## 4. 限制

- 这是一次有界的使用测试，没有无地图对照组，不提供节省 token 或提高成功率的百分比。
- 业务依赖、模型、数据库、前端构建及真实浏览器设备未在此轮运行。
- 地图有助于定位已发现问题；不会自动修复 GPS、知识发布等业务链路。
- 静态接口索引不替代 OpenAPI、权限测试、完整调用图或文档语义审阅。
