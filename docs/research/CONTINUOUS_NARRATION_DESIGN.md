# 连续导览与讲解质量：来源方案整理

来源：`tour-narration-policy`、`tour-context-rag` 和 `guideweave-pilot` 本地工作区的 2026-11-09 至 11-13 设计、调研和试点记录。本文件保存原方案中的产品意图与研究依据；这些独立试点没有整套接入本主线，试点测试结果不能自动算作主线验收。主线已有的下一站提示、播放状态与限制分别见 [连续导览记录](../integration/TOUR_CONTEXT.md) 和 [共享状态盘点](../integration/GUIDE_STATE_INVENTORY.md)。

## 产品目标与保留的设计表述

> 让导游既知道自己提供过什么，也知道游客可能接触了哪些内容，并在事实可靠、游客问题、连续性和自然表达之间协调。成功标准是：中断后不把全文当成听过；重访能接住已确认内容并允许必要重讲；景点专属断言能回溯到知识来源；长讲解有增量解释，短答遵守长度；对不同播放方式和失败场景均可解释状态。

- **接触状态**：区分已展示、完整播放、停止、出错、静音及部分播放。展示不能证明游客已阅读；没有可靠文本与音频对齐时，不推断中断时听到的句子。状态需绑定游览、内容版本和播放会话，旧回调不得回写新会话。
- **依据与讲述分开**：景点事实、运营信息、传说、常识、个人解读及讲解方法各有性质；方法卡提供讲法灵感，不是景区事实证据。已讲过的内容可影响多样性，但不能让回答必需的证据消失。
- **连续而非虚构经历**：当前点、路线、明确提问和已确认的播放记录可影响主题、前后站过渡与必要重讲；推测到访不等于游客亲眼看到、触摸过或产生某种感受。
- **游客控制**：提问可打断讲解，停止后的旧请求和播放回调不影响新请求；继续讲解时只以可靠的播放结果决定已完成内容。内容下架、行程或目录版本变化时重新核查，不静默沿用过期证据。
- **质量与评估**：短问题先回答，长讲解提供增量解释而非单纯增加字数。自检、模型评审和引用匹配均不能代替事实核验；应对相同事实与场景随机配对盲评，并由导游或领域专家核查事实，报告样本、失败与评审一致性。

## 不同试点方案及取舍

早期 GuideWeave 将经审核的讲解单元与依赖关系组合，用测试音验证两站、追问打断、续讲和跨站回顾。它展示了状态驱动选材的可行性；原始记录也指出信息重复和关联较浅，不能据此声称体验优于固定讲解。另一条动态 RAG 试点用有限语料、到访状态和模型生成连续叙述；模拟定位、合成音频、隔离 API 与真实现场的结果需分别报告。主线并未接入这些试点的完整事实库或事实级已听去重。

讲解生成试验经历了“生成后有证据片段校验及有限修复”和“自然正文配合方法卡、小范围检查”等不同方案；这些不是已统一的生产架构。后续方案还提出分句事件、只读诊断、逐句 TTS 与播放回执。某些来源试验记录了真实供应商调用和本机浏览器流程，但也发现缺少证据支持的景点外观描述；这些数据属于对应试验环境，既不是本主线实测，也不能证明事实质量或移动设备体验。

## 方法依据与文书边界

历史调研借鉴了主题组织、问题引导、受众相关性、尊重不同视角和真实性原则。可复核的来源包括 [文旅部导游考试大纲](https://zwgk.mct.gov.cn/zfxxgkml/scgl/202607/P020260730404717970912.pdf)、[美国国家公园管理局解说主题](https://home.nps.gov/articles/000/national-historic-trail-interpretive-themes.htm)、[引导式对话工具](https://www.nps.gov/subjects/climatechange/toolkit-controversy.htm) 和 [ICOMOS 文化遗产解说宪章](https://www.icomos.org/images/DOCUMENTS/Charters/interpretation_e_1.pdf)。这些材料支持设计思路，不代表相关机构认证本系统，也不证明任何体验提升。

可用于后续文书的定位是：**以游客问题、可追溯事实和可靠播放状态共同组织连续讲解，在自然表达中保留不确定性与游客控制。** 实际交付范围和实验结果须按相应版本、资料与设备记录；不以模型自评、模拟播放或单次调用宣称事实正确率、听感改善或行业首创。
