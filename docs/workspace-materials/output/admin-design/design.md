# 景区运营工作台设计 A

日期：2026-11-05。状态：视觉方向已选，详细设计待审阅；未修改产品代码。

## 意图与边界

服务景区内容维护人员，优先让查找知识、修正内容、处理游客问题、配置导游和检查效果更清楚。以现有 Vue 3、Element Plus 页面与 API 为基础，不更换框架，不修改游客端，不把待开发清单当作已实现功能。当前本地工作副本有大量未提交业务变更，实施时必须隔离并保留。

## 方案选择

A：中性浅色工作台，适合长时间维护与多景区复用。B：更强景区品牌和图片表现，利于展示但侵占工作空间。用户选择 A。Logo、景区名称、主题色和数字人预览承载景区气质；不使用装饰渐变、英文眉题、发光和无意义指标卡。

## 页面结构与路由

现有路由保留：dashboard 总览；knowledge 知识管理；blind-spots 知识盲区；avatar 数字人配置；assets 页面与素材；analytics 问答分析；experience-report 游客反馈。导航按工作台、内容运营、游客体验、运营分析分组；登录独立。名称变更不修改路由与鉴权。左栏 208px，正文最大 1440px，24–32px 内边距。顶部是当前位置、当前景区、预览游客端入口；不模拟景区切换器。

## 视觉系统

背景 #F5F6F4，面板 #FFFFFF，文字 #202723，辅助 #59645D，边框 #DCE2DD，强调 #285A46，选中背景 #E8F0EA。主按钮白字深绿底；状态同时提供文字。字体 PingFang SC/Microsoft YaHei/Noto Sans SC/sans-serif；标题 24px，区标题 16px，正文14–16px，辅助12px。间距 4/8/12/16/24/32；控件圆角6px、面板10px。输入与按钮桌面高36px，触屏至少44px。图标用统一线性图标库。颜色集中在后台语义变量中，不覆盖游客端样式。普通文本对比度至少4.5:1，焦点清晰。

## 具体页面

总览：日期范围（仅在接口实际支持时可选）、现有可获得的问答与知识统计、待处理盲区、7日问答趋势、折叠式索引与数据工具。点击待办进入对应盲区页；数量须来自真实数据。首次空库展示新增知识入口。服务状态无探测来源时不显示“运行中”。

知识管理：标题栏新增；搜索、分类和清除筛选；表格显示标题、分类、来源、别名、操作，行高约60px。无可靠更新时间则不加该字段。主编辑采用整页内工作区，返回保留筛选与滚动；标题正文在左，分类来源别名在右。未保存离开必须确认，保存失败保留输入，提交防重复。保留现有校验与接口字段。首次设计稿使用本地示例数据，编辑保存仅为预览内状态。

知识盲区：沿用待处理/已解决，列表显示规范问题、问法、次数与时间；处理详情展示完整原问法和 FAQ 表单。关闭动作仍遵守现有业务接口，不把新增 FAQ 等同于已完成新版复测闭环。未来复测发布另行接入。

数字人配置：稳定预览区域与右侧设置并列，形象/声音分组。保持现有模型加载与配置字段；音色试听属于待核对接口能力，未接入不出现可执行按钮。语速音量有数值、单位与恢复默认（仅恢复表单，保存后才生效）。不重挂载数字人以响应普通表单变化。视觉稿不伪造3D形象，明确预览占位。

页面与素材：品牌与主题、页面模块、媒体素材分组。复用现有欢迎语、字体、模块排序、热线、快捷问题和图片配置接口。预览隔离编辑值和已保存值；未实现实时预览的字段不假装更新。图片展示用途、当前素材、上传与替换状态，失败保留旧图。独立素材库、使用次数统计不在首轮范围。

问答分析/游客反馈：保留现有指标定义与周期，优先一屏一个主题；趋势后接明细。满意度与模型情绪分开，未获得真实分母不显示百分比。跨图表筛选只在接口都支持同一范围时提供。点击下钻仅在已有明细入口时启用。

登录：单一清晰表单，管理密码可见切换、提交中、失败信息与键盘提交；不显示示例账号、默认密码、虚构版本号。

## 已有与未来能力

首轮只改呈现与已有交互组织。知识草稿版本、批量发布、冲突对比、持久发布任务、游客端正式预览、复测闭环、角色分派与景区切换属于独立后续能力，不在首轮增加伪入口。生产中隐藏未接入按钮；评审稿可以用明确禁用和“待接入”标签解释。

## 异常与响应式

加载用结构骨架；请求失败显示重试并保留原数据，不能用0替代失败；筛选无结果提供清除；原始空库提供新增；局部失败不锁整页。1024px以下压缩导航，768px以下导航折叠并使用单列内容；手机列表保留标题与主操作，其他信息在详情，不强行缩小文字。编辑输入字号至少16px；弹层键盘可关闭、焦点可返回；编辑区域的未保存状态可被读屏感知。

## 原型与验证

配套交互稿覆盖总览、知识列表/编辑、盲区、数字人配置、页面与素材、分析与反馈，均使用明确标注的示例数据，不联网、不读写后台。关键交互为导航、搜索、编辑保存及本地设置切换。设计评审检查1024/736/390px无页面横向溢出、关键按钮可键盘操作、长文本换行、空筛选结果。实施后再按项目要求运行 npm test、npm run build，并检查真实浏览器、网络失败与登录退出。
