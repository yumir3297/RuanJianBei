## 录制前检查

- 固定代码提交、模型标识、知识版本和景区数据；记录环境、权限、供应商调用结果及样例数据来源。不得展示 key 或游客隐私。
- 用 HTTPS 和目标手机验证相机、麦克风、定位与音频播放；预演失败及降级，不用模拟画面冒充真实服务。
- 确认 API 和独立 worker 指向同一隔离数据库；检查待处理任务和费用限制。录制后检查引用指向、字幕、音画同步和分辨率。
- 真实服务或设备不可用时明确说明未完成对应镜头；正式提交前重新核对官方规则，勿自动公开上传或部署。
