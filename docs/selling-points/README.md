本目录用于沉淀可用于项目介绍、答辩和演示的技术卖点。每个卖点都应对应实际代码、验证证据和已知边界；“创新”指面向数字人导游场景的架构组合与工程适配，不暗示相关底层技术由本项目首创。

## 使用约定

- 对外表述优先采用文档中的“可直接讲”版本。
- 尚在补丁、未合入或仅仿真验证的内容必须标为规划/实验，不得作为已交付效果宣传。
- 性能收益只有在同设备、同网络、同模型和同负载下完成前后对照后，才能写出具体百分比或容量数字。
