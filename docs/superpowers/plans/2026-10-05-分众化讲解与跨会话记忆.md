# 分众化讲解 + 跨会话记忆 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让数字人导游"对谁讲、怎么讲"可被服务端正确区分，并让复访游客被认出来——分众化讲解（儿童/休闲/深度）成为服务端一等参数，"讲解方式"不再靠客户端拼接问题前缀；同时新增按稳定 visitor_id 聚合的跨会话游客记忆，复访时注入"欢迎回来 + 已游览景点 + 关注点"。

**Architecture:** 两条改动都收敛到同一个注入点——`EvidencePromptBuilder.build()` 的 system prompt 组装。Phase A 把 `audience` 从"客户端问题前缀"上移为 `ChatRequest.audience`，透传到 LLM system prompt，并把 `audience` 纳入问答缓存键；Phase B 新增独立表 `visitor_memories`（按 `visitor_id` 聚合，与 `session_id` 解耦），在 `stream_chat` 开头读记忆、结尾写记忆，读到的记忆同样注入 system prompt。两条相互独立，可分别上线。

**Tech Stack:** FastAPI + Pydantic v2 + SQLAlchemy async + Alembic + pytest 8.4；Vue 3 `<script setup>` + Pinia；DeepSeek 兼容 Chat Completions（流式）。

**设计依据:** `docs/superpowers/specs/2026-10-02-multi-scenic-guide-proposal.md`（多景区隔离要求）、`docs/superpowers/specs/2026-10-04-geolocation-audio-guide-design.md`（讲解链路复用范式）。

## 关键前置事实（已核实，实现时不要再假设）

1. **分众化已经"半实现"，而且是坏的。** `frontend/src/views/tourist/ChatView.vue:745-750` 已在客户端把问题拼成 `"请用小朋友能听懂的语言解释：" + query`。这个前缀会一路污染 `raw_query`、`normalized_query`、FAQ 精确匹配与 RAG 检索，并且**决定了问答缓存键**（缓存键由 `normalized_query` 派生）。后台 `explanationLevel` 的取值是 `child | adult | expert`，UI 文案是"亲子讲解 / 休闲讲解 / 深度讲解"。
2. **`persona` 目前根本没从游客端发出去。** `frontend/src/stores/chat.js:119` 有 `persona: options.ttsConfig?.persona || null`，但 `ChatView.vue:754` 构造的 `ttsConfig` 只有 `voiceType/speechRate/volume`。全仓 `frontend/src` 中 `persona` 只出现这 1 次。所以 `request.persona` 恒为 `None`，`polish_answer()` 恒回退 `hanfu`。**本计划不改动该行为**，只在风险清单里标注。
3. **`audience_type` 与"讲解方式"是两个不同概念，不要合并。**
   - `_infer_audience_type()`（`pipeline.py:102`）产出 `family | culture | free | leisure | general`，**只用于路线推荐**（`RecommendRequest.audience_type`）。
   - 新引入的 `ChatRequest.audience` 是讲解口径 `child | adult | expert`。
4. **问答缓存键不含受众。** `build_selection_cache_key()`（`guided_selector.py:29`）的 payload 只有 `query / mode / attraction_id / topic_key / route_id / answer_namespace`，前缀是 `qa:v3:`。`answer_namespace` 内含 `prompt=SYSTEM_PROMPT_VERSION`，所以**改 prompt 会让全量缓存自然失效**，但**受众维度仍必须显式入键**，否则儿童版答案会被成人版命中。

8. **`BehaviorSummary` 与游客行为无关**，它是那份 `.xlsx` 数据集的统计摘要（`models/behavior_summary.py`），不要复用。
9. **Alembic 未开 `render_as_batch`**（`alembic/env.py:66-71`），SQLite 下 `ALTER TABLE` 会失败。因此**不改 `visitor_profiles` 表结构，改为新增独立表**（纯 `create_table`，SQLite/PostgreSQL 都安全）。

```python
AUDIENCE_STYLES: dict[str, str] = {

        "补充年代、形制、教义源流、工艺等细节；资料若有分歧可指出存疑。\n"
        "严禁超出【参考资料】编造事实。"
    ),
}


def normalize_audience(value: str | None) -> str | None:
    """把外部传入的讲解口径收敛到白名单；未知值返回 None（等价于不指定）。"""
    if value is None:
        return None
    key = value.strip().lower()
    return key if key in VALID_AUDIENCES else None


def get_audience_style(key: str | None) -> str:
    """返回该受众的 system prompt 风格块；adult/未指定返回空串。"""
    normalized = normalize_audience(key)
    if normalized is None:
        return ""
    return AUDIENCE_STYLES[normalized]
```

```python
    def build(
        self,
        query: str,
        documents: list[RetrievedDocument],
        *,
        persona: str | None = None,
        audience: str | None = None,
        memory: str | None = None,
    ) -> EvidencePrompt:
        effective_persona = persona or self.persona_key
        p = get_persona(effective_persona)

        blocks: list[str] = [p["intro"], p["style"]]
        audience_block = get_audience_style(audience)
        if audience_block:
            blocks.append(audience_block)
        if memory and memory.strip():
            blocks.append(memory.strip())
        blocks.append(EVIDENCE_RULES)
        system_prompt = "\n\n".join(blocks)

        evidence = [
            EvidenceItem(
                evidence_id=f"证据{index}",
                title=document.title.strip() or "未命名资料",
                source=document.source.strip() or "未标注来源",
                content=self._document_content(document)[: self.max_chars_per_document],
            )
            for index, document in enumerate(documents[: self.max_documents], start=1)
        ]
        context = "\n\n---\n\n".join(
            f"[{item.evidence_id}]\n标题：{item.title}\n来源：{item.source}\n内容：{item.content}"
            for item in evidence
        )
        user_message = f"问题：{query.strip()}\n\n【参考资料】\n{context}"
        return EvidencePrompt(
            messages=[
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_message},
            ],
            evidence=evidence,
        )
```

```python
def build_selection_cache_key(
    normalized_query: str,
    selection: SelectionContext,
    *,
    answer_namespace: str = "default",
    audience: str | None = None,
) -> str:
    """问答缓存键。

    未指定与 adult 视为同一档（adult 不加风格块），避免同义键分叉。

        "query": normalized_query,
        "mode": selection.mode,
        "attraction_id": selection.attraction_id,
        "topic_key": selection.topic_key,
        "route_id": selection.route_id,
        "audience": audience or "adult",
        "answer_namespace": answer_namespace,
    }
    serialized = json.dumps(payload, ensure_ascii=False, sort_keys=True, separators=(",", ":"))
    return f"qa:v4:{hashlib.sha256(serialized.encode('utf-8')).hexdigest()}"
```

```python
from __future__ import annotations

import json
import logging

from sqlalchemy import delete, select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.visitor_memory import VisitorMemory

logger = logging.getLogger(__name__)

MAX_ATTRACTIONS = 20
MAX_TAGS = 12


def _load_list(raw: str | None) -> list[str]:
    try:
        value = json.loads(raw or "[]")
    except (TypeError, ValueError):
        return []
    if not isinstance(value, list):
        return []
    return [str(item).strip() for item in value if str(item).strip()]


class VisitorMemoryRepository:
    """按 (visitor_id, site_id) 聚合的跨会话记忆读写。"""

    def __init__(self, session: AsyncSession) -> None:
        self.session = session

    async def get(self, visitor_id: str, *, site_id: str = "default") -> VisitorMemory | None:
        stmt = select(VisitorMemory).where(
            VisitorMemory.visitor_id == visitor_id,
            VisitorMemory.site_id == site_id,
        )
        result = await self.session.execute(stmt)
        return result.scalar_one_or_none()

    @staticmethod
    def decode(memory: VisitorMemory) -> dict:
        return {
            "visitor_id": memory.visitor_id,
            "site_id": memory.site_id,
            "visit_count": int(memory.visit_count or 0),
            "visited_attractions": _load_list(memory.visited_attractions),
            "preference_tags": _load_list(memory.preference_tags),
            "narration_audience": memory.narration_audience or "adult",
            "first_seen_at": memory.first_seen_at,
            "last_seen_at": memory.last_seen_at,
        }

    async def record_visit(
        self,
        *,
        visitor_id: str,
        session_id: str = "",
        site_id: str = "default",
        attraction_title: str | None = None,
        interests: list[str] | None = None,
        narration_audience: str = "adult",
    ) -> VisitorMemory:
        memory = await self.get(visitor_id, site_id=site_id)
        if memory is None:
            memory = VisitorMemory(
                visitor_id=visitor_id,
                site_id=site_id,
                visited_attractions="[]",
                preference_tags="[]",
                narration_audience=narration_audience or "adult",
                visit_count=0,
                last_session_id="",
            )
            attractions: list[str] = []
            tags: list[str] = []
        else:
            attractions = _load_list(memory.visited_attractions)
            tags = _load_list(memory.preference_tags)

        if attraction_title and attraction_title.strip() and attraction_title not in attractions:
            attractions.append(attraction_title.strip())
        for tag in interests or []:
            if tag and tag not in tags:
                tags.append(tag)

        # 只有换会话才算一次新到访，避免同一会话内多轮灌水
        if session_id and session_id != (memory.last_session_id or ""):
            memory.visit_count = int(memory.visit_count or 0) + 1
            memory.last_session_id = session_id

        memory.visited_attractions = json.dumps(attractions[-MAX_ATTRACTIONS:], ensure_ascii=False)
        memory.preference_tags = json.dumps(tags[-MAX_TAGS:], ensure_ascii=False)
        if narration_audience:
            memory.narration_audience = narration_audience
        self.session.add(memory)
        await self.session.commit()
        await self.session.refresh(memory)
        return memory

    async def delete(self, visitor_id: str, *, site_id: str = "default") -> int:
        result = await self.session.execute(
            delete(VisitorMemory).where(
                VisitorMemory.visitor_id == visitor_id,
                VisitorMemory.site_id == site_id,
            )
        )
        await self.session.commit()
        return int(result.rowcount or 0)
```

```python
"""把结构化游客记忆渲染成可注入 system prompt 的短文本。

设计约束：
- 这是"语气与信息顺序"的输入，不是景区事实来源；
- 必须短（默认 ≤ 8 个景点），避免挤占证据预算；
- 首访且无任何信号时返回空串，不产生任何 system prompt 噪声。
"""

from __future__ import annotations

AUDIENCE_PREFERENCE_LABEL: dict[str, str] = {
    "child": "希望用孩子能听懂的方式讲解",
    "expert": "希望听到更专业、更深入的细节",
}

MAX_ATTRACTIONS_IN_PROMPT = 8
MAX_TAGS_IN_PROMPT = 6


def build_memory_prompt(
    memory: dict | None,
    *,
    max_attractions: int = MAX_ATTRACTIONS_IN_PROMPT,
    max_tags: int = MAX_TAGS_IN_PROMPT,
) -> str:
    if not memory:
        return ""

    visit_count = int(memory.get("visit_count") or 0)
    attractions = [str(item) for item in (memory.get("visited_attractions") or []) if str(item).strip()]
    tags = [str(item) for item in (memory.get("preference_tags") or []) if str(item).strip()]

    has_attractions = bool(attractions)
    has_tags = bool(tags)
    if visit_count < 2 and not has_attractions and not has_tags:
        return ""

    lines: list[str] = ["【游客记忆】"]
    if visit_count >= 2:
        lines.append(f"这位游客是第 {visit_count} 次来到本景区，可在合适时机自然地说一句欢迎回来。")
    if has_attractions:
        lines.append("已经游览过：" + "、".join(attractions[:max_attractions]) + "。")
    if has_tags:
        lines.append("关注点：" + "、".join(tags[:max_tags]) + "。")

    preference = AUDIENCE_PREFERENCE_LABEL.get(str(memory.get("narration_audience") or ""), "")
    if preference:
        lines.append(f"讲解偏好：{preference}。")

    lines.append("以上记忆只用于调整语气与信息顺序；不要把记忆当作景区事实依据，也不要生硬复述整份记录。")
    return "\n".join(lines)
```

```js
const VISITOR_STORAGE_KEY = "a5-visitor-id";

/**
 * 稳定的匿名游客标识，存在 localStorage（跨会话保留）。
 * session_id 仍然只存活在 sessionStorage，两者用途不同：
 * session_id 标识"这一次游览"，visitor_id 标识"这个人"。
 */
export function getVisitorId() {
  const fallbackId = `visitor-${Date.now()}-${Math.random().toString(36).slice(2, 10)}`;
  if (typeof localStorage === "undefined") return fallbackId;
  try {
    const existing = localStorage.getItem(VISITOR_STORAGE_KEY);
    if (existing) return existing;
    const visitorId = globalThis.crypto?.randomUUID?.() || fallbackId;
    localStorage.setItem(VISITOR_STORAGE_KEY, visitorId);
    return visitorId;
  } catch {
    // 无痕模式等场景 localStorage 会抛异常，降级为内存 id，不影响聊天
    return fallbackId;
  }
}

export function clearVisitorMemory() {
  try {
    localStorage.removeItem(VISITOR_STORAGE_KEY);
  } catch {
    // 忽略：清理失败不应阻断聊天
  }
}
```

## 追加批次（2026-10-05）：FAQ 快路径感知受众

**背景：** 上一批交付后 FAQ 快路径仍绕过 LLM，命中 FAQ 时切换讲解方式没有反应（原 R5）。

**改法：** 不改数据、不新增 FAQ 变体文案（那需要为每条 FAQ 手写三份），而是把 FAQ 官方答复**当作一条证据**交给已有 LLM 链路换风格。

| 场景 | 行为 |
|---|---|
| FAQ 命中 + `adult` / 未指定 | **完全不变**：直接返回 FAQ 原文，零 LLM、零检索 |
| FAQ 命中 + `child` / `expert` | 跳过 RAG 检索，把 FAQ 原文作为唯一证据交给 LLM 改写；结果按受众专属 `qa:v4` 键缓存 |
| FAQ 命中 + 受众非默认 + LLM 降级 | **回落 FAQ 原文**，不把"AI讲解服务暂时不可用"甩给游客；且不写缓存（避免一次抖动长期污染该受众缓存） |

**改动文件：**
- `backend/app/services/qa/pipeline.py`：`_faq_evidence_document()`；FAQ 分支按 `get_audience_style(audience)` 分流；`documents`/`sources` 来源分叉（FAQ 证据 vs RAG 检索）；新增 `llm_hit_level` / `llm_fallback_hit_level`；降级回落。
- `backend/app/api/insights.py`：`_hit_level_label()` 支持 `faq_*_styled` 与 `*_styled_llm_fallback`，后台看板显示"FAQ 精确匹配（按受众改写）"。

**新增命中层级（写入 `chat_logs.hit_level`）：**

| hit_level | 含义 |
|---|---|
| `faq_exact` / `faq_fuzzy` / `faq_semantic` | 原有：FAQ 原文直出（受众为 adult/未指定） |
| `faq_<level>_styled` | FAQ 原文经 LLM 按受众改写 |
| `faq_<level>_styled_llm_fallback` | 想要改写但 LLM 降级，已回落 FAQ 原文 |

**新增测试（9 个）：** `test_pipeline.py` 5 个（默认受众仍零 LLM、adult 等价、child 走 LLM 且不检索、受众专属缓存、LLM 降级回落原文）；`test_insights_labels.py` 4 个。

**仍不做：** 静态路线快路径（`_build_static_route_answer`）未感知受众——它输出的是结构化行程模板，交给 LLM 重写有破坏排版与行程事实的风险，需单独评估。
