# 生产环境管理员鉴权加固设计

## 发现

- 管理员 API 已要求 Bearer token；token 是带时间戳的 HMAC-SHA256，但默认签名密钥固定为公开字符串 `a5-scenic-admin-secret-key`。
- 默认后台密码为 `admin123`。当前 `/ready` 只在 `competition_mode=true` 时标记默认密码，生产环境未必启用该开关；token 默认密钥没有就绪门槛。
- 游客聊天、ASR、视觉和路线接口是公开游客流程。给这些接口套管理员登录会破坏产品流程；当前 `CapacityLimiter` 仅限制单进程同时运行数，不限制一段时间内请求数，也不跨 worker。

## 本轮修复

- `app_env` 为 `production` 或 `prod` 时，启动前检查管理员密码非默认且至少 12 字符；token secret 非默认且至少 32 字符。缺项 fail-fast，不打印秘密。
- `/ready` 在生产环境报告同一项配置失败；非生产开发环境继续使用现有本地默认值。
- 不更改游客接口的认证策略，不把单进程并发限制称作速率限制。

## 后续边界

正式访客限流需先明确反向代理与可信客户端 IP 来源。未配置可信代理时不能直接信任 `X-Forwarded-For`；多 worker/多实例应由网关或共享存储实现时间窗口限制。当前把该项留在清单并注明边界。
