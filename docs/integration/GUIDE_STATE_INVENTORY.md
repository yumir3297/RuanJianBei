|---|---|---|

| CASS 决策与安全事件 | `useGuideContext.js` 为组件创建的 `createGuideController`，`scheduler.js` 存在 `activeSafetyEvent`/generation | GuideContextStatus 通过 `interrupt` 通知 ChatView 停止播放；该状态当前没有直接传递给 MapView 的自动讲解调度 |
| 地图自动讲解 | `useNarration.js` 管理 activeSpot、pending 和 generation；`guidePlayback.js` 共享演示景点完整音频播放记录；MapView 管理请求和播放 session | 只在当前自动讲解的完整音频结束回调中记录；浏览器短片段、静默与中断不计完成。景点名称是演示目录标识，不等同已发布知识、真实到访或行程完成，不跨刷新保存，也尚未接入 GuideWeave 的事实级记录 |
| 地图位置及激活 | `MapView` 的 `useGeolocation` 是定位来源；`stores/guideLocation.js` 是游客端运行时共享视图 | ChatView 从共享视图向 CASS 传递；地图隐藏清除位置且拒绝隐藏期间的更新，不持久化；坐标精度及真实设备生命周期仍需验证 |
| 连续导览试点 | 另一来源的 `tourGuide.js` 和 `useGuideWeavePilot.js` 分别维护 tour ID、revision、当前景点、已听事实/单元和请求 | 未接入集成工作区；不得直接同时启用多套调度或复制已保存游览事实 |

## 优先待解决问题

1. 安全事件已连接地图忙碌状态和普通讲解入口，仍需在真实浏览器验证中断、待播项、重新核验及用户确认的完整链路。
2. 当前音频完成已区分静默和取消，但跨站已听事实、部分播放和浏览器短片段仍未统一；不能把 silent/失败/取消作为完成。
3. 引入共享视图时保留服务端行程版本与共享播放器的权威地位。组件通过事件/action 交互，检查切换景点、用户停止和安全事件导致的旧响应失效。
4. 需要结合现有组件测试建立跨组件回归：预警期间尝试地图自动讲解、迟到结果、预警重新核验、恢复、取消与实际音频完成。

## 已实施的第一步与剩余限制

- 游客端 `stores/guideSafety.js` 维护 CASS 安全暂停；`useGuideContext` 将控制器事件投影到该状态；`ChatView` 在暂停时阻止普通查询、重试和回放，并将暂停状态作为忙碌条件传给地图。模拟预警确认后仍须显式点击继续；真实预警确认、失去来源、或返回 `none_verified` 均不证明解除，暂停继续保留。模拟事件不能解除真实预警造成的暂停。
- 真实预警暂停在同一标签页的 `sessionStorage` 中保存无详情标志；刷新会恢复暂停，标签页关闭、存储被禁用或清除后不保证保留。模拟暂停只在内存中保留。真实预警没有“可靠解除”数据契约，因此本版没有通过重新核验自动恢复的路径；真实场景不能据此宣称完整的安全闭环。
- 现有播放器增加 `onOutcome`，区分音频完成与静默不可用；取消后不派发完成。自动讲解只有当前会话完整音频完成才会写 `useNarration.completed`，浏览器短片段不写；相关单元测试已通过。真实浏览器、媒体错误和跨站状态联动仍需验收，不能据此认为 GuideWeave 已接入。
- 自动测试覆盖控制器和共享 store 的模拟确认/显式恢复、真实预警不因确认或模拟事件解除；尚未做真实浏览器跨组件和设备联测。
- 2026-11-13：地图定位、模式和激活状态改由游客端 `guideLocation` store 提供，地图通过 action 更新，ChatView 从同一状态传给情境组件。隐藏地图清除位置并拒绝后续更新，重新打开以定位组件当前状态初始化；不写持久存储。共享定位测试覆盖激活、更新、清除和隐藏后迟到更新；真实定位、跨组件浏览器与设备联测尚待验收。行程、已听记录及播放器仍分别有各自权威来源，不表示全部状态已统一。
- 2026-11-13（续）：定位监听增加 generation，停止、改用模拟或重新启动后旧回调不能更新定位或触发模拟降级。Chrome 在 API 和浏览器定位均为模拟的条件下验证地图打开、位置进入情境面板、收起清空、重新打开及旧监听错误回调隔离；脚本见 `frontend/tests/e2e/guide-location-smoke.mjs`。真实 GPS、权限行为和设备仍未验收。
- 2026-11-13（播放状态）：借鉴原连续导览仅在完成时记录的原则，地图使用 `guidePlayback` 保存演示景点完整音频结果，聊天辅助栏可读取；地图切换不清除，页面刷新清除。原方案的 tour ID、知识事实 ID 与 corpus 版本在当前演示地图没有可靠对应关系，未推断或迁移这些事实。播放器与调度测试覆盖完整、静默、中断、旧会话及地图重置；真实音频设备、事实级去重和连续导览仍未验收。
- 2026-11-13（安全与地图浏览器联动）：本机 Chrome 使用模拟 API 和模拟预警，地图打开时验证普通提问按钮在预警后禁用、确认提醒后仍禁用、显式恢复后重新可用；见 `frontend/tests/e2e/guide-safety-map-smoke.mjs`。未启动真实音频或验证待播、迟到响应和真实预警，因此不能据此认定完整安全中断链路通过。
